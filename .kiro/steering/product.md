# Product Overview

## What is SPHR?

SPHR (Simple Personal Healthcare Record) は、個人ヘルスケアレコードを管理するWebアプリケーションです。日々の健康情報を記録・蓄積し、定期健診時にかかりつけ医へ報告するための時系列データ管理を実現します。

## Core Features

- **健康情報登録**: 血圧（上/下）、脈拍、体重などの日々の健康データを登録・変更・削除
- **データ参照**: 過去に登録した健康情報を日付や期間を指定して参照
- **データ分析**: 統計値（最大・最小・平均）の計算、折れ線グラフ、30日移動平均の描画
- **データ出力**: 指定期間の健康データをPDF、CSV等で出力し、医療機関へ提供
- **データ種類管理**: 個人のニーズに合わせたデータ項目のカスタマイズ
- **過去データ移行**: 既存の3年分のデータをCSV形式から移行

## Target Use Case

### Primary Scenarios
1. **日常的な健康管理**: スマホやPCから日々の健康情報を短時間（30秒以内）で記録
2. **健康傾向の把握**: 蓄積されたデータから統計値とグラフで健康状態の傾向を視覚的に理解
3. **医師との情報共有**: 定期健診時にかかりつけ医へ日常的な健康データを効率的に報告

### User Needs
- **既存ツールの課題解決**:
  - EPARK等の既存アプリは機能が多く、カスタマイズができない
  - スマートウォッチでは体重などの一部情報に対応できない
  - 個人が長期的に健康情報を記録・管理する適切なツールが不足

- 継続利用のモチベーション向上

### 医療連携

- 質の高い診療や健康指導への貢献
